# 首版发布验证

本记录针对本仓库首版发布整理，不作为通用测试套件。

## 实测环境

macOS 13，Python 3.11，依赖按 `requirements.txt` 和 `requirements-review.txt` 安装。浏览器操作使用本机 Chrome。未在 Windows、Linux 实机运行，不把跨平台可用性宣称为已验收。

## 必要验收结果

- Python 脚本语法解析通过。
- 从正式轮廓源构建全字版：4616 个云篆字形，907 个释文字，1211 个 cmap 映射；另有 `.notdef` 与空格。
- 与整理前完成版逐字比较轮廓坐标、轮廓终点及点标志：差异 0；cmap 相同。
- 同一环境连续两次构建：文件逐字节相同。
- 字体写入版权、OFL 说明及链接；嵌入标记为 `fsType=0`；保留 `aalt`、`salt`、`calt`。
- 提供本地原扫描后，12 页校对网页全部生成。
- 原编辑器自带自检与发布版自检均通过：切笔画、改归属、改释文、撤销后保留切分及当前字定位。
- 浏览器实际点击更换默认字形，经服务保存，刷新后恢复一致。
- 浏览器实际点击释文、通过输入框改字，经服务保存，刷新后恢复；随后 dry-run 和实际导入到独立副本，标注变更及备份存在。
- 版本冲突请求返回 409，已有修订内容不变；跨站来源写入返回 403。
- 代码、轮廓源、备份、列标注及路径穿越请求均不能经服务下载；允许的单字 PNG 可正常读取。

所有修改型验证均在独立副本进行，没有把测试用字或测试审阅进度写入发布源数据。

## 首版边界

不测试／不交付通用 OCR、新底本配准、自动重新矢量化、云端协作与公网部署。原扫描不随仓库分发；未安装跨平台字体样张测试依赖，也未新增长期测试框架。
