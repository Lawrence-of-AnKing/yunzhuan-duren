# 校对与修改

工具仅适用于本书现有 12 页版式和标注，不是通用古籍 OCR 软件。首版保留必要功能，不包含从另一份 PDF 自动切分全书的历史实验链。

所有命令在仓库根目录、已激活 Python 3.10+ 虚拟环境后执行。

## 一、挑选默认字形

无需原扫描或额外图像依赖：

```sh
python font/build_variants_page.py
python review_server.py
```

打开 `http://127.0.0.1:8765/font/variants.html`。搜索汉字、查看原书位置、挑默认字形或调整组。修改自动写入 `edits/font_choices.json`，旧版另保留 `.bak`。只有通过此服务打开才能保存到文件；直接双击 HTML 仅保存到浏览器。

完成后运行 `python font/build_font.py`。分组调整只改变默认、选择顺序及轮换，不会删掉任何云篆。页面上显示的“合并”指分组，不表示本仓库生成删减字形的合并版。

服务只监听本机，不开放外部监听参数，不应反向代理到公网。关闭时在终端按 Ctrl+C。可用 `--port` 选择其他本机端口。

## 二、笔画级校对

```sh
python -m pip install -r requirements-review.txt
```

自行提供工作底本对应的 12 张 PNG，放入本地 `pages/`，命名为 `p01.png` 至 `p12.png`。扫描页不入 Git；页面尺寸、方向、裁切必须与现有标注一致。各列文件中的 `origin` 是原页像素坐标，换扫描件需要重新对齐，本版不自动配准。

若原页保存在仓库外，可用环境变量 `YZ_PAGES_DIR` 指向该目录。它只供生成与导出程序读取，不会使服务开放原页目录。

```sh
python build_all.py
python review_server.py
```

打开 `http://127.0.0.1:8765/index.html`：点列进入大图；用刷子修改笔画归属，用刀切开粘连；可改释文、撤销、查看原图幕帘，修订自动保存。生成的 HTML 内嵌原扫描，不可随 Git 发布。

检查并导入：

```sh
python import_all.py --dry
python import_all.py
```

导入前备份到 `_preimport/`，并检查网页生成编号及墨迹范围。修订导入列标注并重新导出对应页的单字 PNG。

页面版本由数据与模板内容计算。同源数据重建不改变版本；版本不符时前端和服务端均拒绝覆盖旧修订。导入后，将对应 `edits/yunzhuan_pNN_edits.json` 移到本地 `edits/archive/` 再重新生成页面；不要在未导入前归档或删除它。归档保留可追溯性，不入 Git。

## 三、从校对结果更新字体

**PNG 与定稿轮廓分开保存。** 笔画导入不会重新矢量化，也不会自动改变 `font/outlines.json`。这是为了保持已完成字体的轮廓稳定，不把跨环境矢量化差异带入正式版本。

- 只改默认字形、分组：用第一节的网页保存，直接重建字体。
- 改实际笔画：导入并检查 PNG；为该字准备修正后的二次曲线，按同一原书字形 ID 更新 `font/outlines.json`；然后重建。
- 改释文对应：同时更新 `font/variants.json` 的字形归属、`glyphs/pNN/items.json` 的释文及相应轮廓索引。调整映射会改变生成编号，旧 `edits/font_choices.json` 必须先人工迁移并核对，不能仅修改编号强行套用。

`font/outlines.json` 格式为 `{format: 1, unitsPerEm: 1000, glyphs: {原书字形ID: 指令列表}}`。每条指令为 `[命令, 点列表]`，命令使用 fontTools RecordingPen 的 `moveTo`、`lineTo`、`qCurveTo`、`closePath`、`endPath`；点是字体坐标 `[x,y]`，`qCurveTo` 可包含 `null`。此文件就是可编辑的正式轮廓源，不是缓存。

首版不附带新的轮廓编辑器或自动矢量化工具。新增／删除字形属于后续字库版本变更，须同步调整构建中的数量校验及说明。

## 四、数据约定

- `v5/` 是第 1 页；`v6p02/` 至 `v6p12/` 对应第 2–12 页。名称为原工程遗留，不表示它们是可删的历史备份。
- 每列 `.npz` 保存 `ink`（墨迹）和 `P`（笔画片编号图）；同名 `.json` 保存 `owner`（片号归属）、`cells`（释文与字序）、`origin`（原页起点）。
- 网页修订中 PNG 的 R/G 通道分别存片号低／高 8 位；导入时核对墨迹范围不变。
- 字形 ID 如 `p01r1c01g1` 表示页、栏、列与该列第几个字；`glyphs/pNN/items.json` 提供位置索引。
- 如需生成带中文字的复查图，额外用 `YZ_LABEL_FONT` 指定自行安装、许可合适的中文字体；通常网页校对不需要此设置。
