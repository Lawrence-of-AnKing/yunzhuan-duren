# 来源、许可与发布范围

## 底本与整理方法

本字体取自《正统道藏》本《元始无量度人上品妙经》云篆本。所用工作副本共 12 页，逐字切分得到 4616 个云篆，释文对应 907 个字。

原工程交接记录明确工作 PDF 来自 ctext（中国哲学书电子化计划），但未保留具体条目 URL。古籍原作属于公有领域；扫描机构及现代影印本的出版信息仍未确认。因此本仓库不分发原 PDF、整页扫描 PNG、内嵌整页扫描的校对网页或第三方参考资料，也不宣称拥有这些材料的版权。需要原扫描进行笔画级校对时，请自行取得合法副本，并核对版本与尺寸。

本项目公开的是字体整理成果、逐字字形源与人工标注、构建及校对代码。源文件不包含现代影印本的封面、说明、排版说明或数据库页面。古籍本身的公有领域地位不使第三方网站或现代出版物中的所有内容自动进入公有领域。

释文保留底本实际所印文字，不以通行本经文擅自改字。既有人工修正已体现在随仓库发布的字形及标注中；不分发包含私人信息的历史审阅日志、浏览记录、原始备份。

## 授权边界

以下字体软件使用仓库根目录 `OFL.txt` 所载 **SIL Open Font License 1.1**：

- `dist/*.ttf`；
- `font/outlines.json`、`font/variants.json`；
- `glyphs/` 中的单字 PNG 与位置、释文数据；
- `v5/`、`v6p02/` 至 `v6p12/` 中的笔画片和人工标注；

## 第三方依赖

依赖由包管理器安装，本仓库不附带其实现代码。各依赖保持原有许可证：

| 依赖 | 用途 | 上游许可证 |
|---|---|---|
| fontTools | 构建 TTF 与 OpenType 表 | MIT |
| opencc-python-reimplemented | 繁简映射 | Apache-2.0 |
| NumPy | 校对数组 | BSD-3-Clause |
| opencv-python-headless | 校对图像读写 | Apache-2.0；发行包另含第三方声明 |
| Pillow | 复查图输出 | HPND（Pillow 许可文本） |
